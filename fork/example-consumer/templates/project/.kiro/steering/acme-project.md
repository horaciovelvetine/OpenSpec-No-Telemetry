# Example project guidance

This project uses the example consumer with OpenSpec for spec-driven changes.

- Explore an idea with `/opsx-explore`, plan a change with `/opsx-propose`, implement it with `/opsx-apply`, and finish with `/opsx-archive`.
- `openspec status --json` shows where a change stands; `openspec list` shows all changes.
